Sales Savvy

A full-stack e-commerce application: React storefront, Spring Boot REST API, MySQL, JWT login, online payments in test mode, and a Docker setup that starts everything with one command.

Backend code Frontend code Run it with Docker

What it does

Customers

  • Register, log in, browse and search products
  • Cart tied to the logged-in user
  • Checkout that reserves stock and opens the Razorpay popup
  • Track orders, pay later, cancel unpaid orders

Admins

  • Manage products, categories and order statuses
  • Upload product images
  • Optional AI button that drafts product descriptions

Under the hood

  • JWT authentication with ADMIN and CUSTOMER roles
  • Customers can only read, pay for or cancel their own orders
  • Payment signatures verified on the server
  • Unit tests and GitHub Actions builds

Tech stack

React (Vite), React Router, Axios, Bootstrap · Java, Spring Boot, Spring Security, Spring Data JPA · MySQL 8 · JWT, BCrypt · Razorpay (test mode) · JUnit 5, Mockito · Docker, Docker Compose, nginx, GitHub Actions

Run it yourself

You need Docker Desktop. Clone the three repositories side by side and start everything:

git clone https://github.com/Babu-Shigihalli/sales_savvy_docker.git
cd sales_savvy_docker
git clone https://github.com/Babu-Shigihalli/sales-savvy-backend.git
git clone https://github.com/Babu-Shigihalli/sales-savvy-frontend.git
docker compose up --build

The README in the Docker repository explains the required settings in the .env file and how to create the first admin.
